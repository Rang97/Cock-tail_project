# Cock-tail

`TheCocktailDB API`를 활용하여 다양한 칵테일을 둘러보고 원하는 칵테일을 검색 및 저장할 수 있는 웹 애플리케이션입니다.

## 주요 기능

- 칵테일 검색
- 재료 기반 필터링
- 무한 스크롤로 칵테일 목록 탐색
- 북마크(마이바) 기능
- 기본적인 네비게이션 및 뷰 전환
- 다크 모드 기능

## 사용 기술

- React
- Vite
- TanStack React Query
- Axios
- Tailwind CSS

## 빌드

```bash
npm run build
```

## 참고

- 칵테일 데이터는` TheCocktailDB API`를
- 북마크 정보는 브라우저의 `localStorage`에 저장
